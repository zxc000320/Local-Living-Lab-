# 🚭 Smoking Time Stealer

> 흡연 욕구가 드는 3분, 담배 대신 퍼즐로 그 시간을 훔쳐갑니다.

**Smoking Time Stealer**는 네모네모로직(Nonogram) 퍼즐과 알람 기능을 결합한 **금연 기능성 안드로이드 게임**입니다.
로컬 리빙랩 팀 프로젝트로, 팀 **시가락 브레이커즈(Cigarette Breakers)** 가 Unity로 제작했습니다.

## 💡 기획 의도

기존 금연 교육은 경고문·영상 위주의 일방향 정보 전달이라 실제 행동 변화로 이어지기 어렵고, 자극적인 공포 소구는 오히려 거부감을 줍니다.
이 게임은 **게임 기반 학습(GBL)** 방식으로 접근합니다.

- 흡연 욕구가 드는 시간대에 **알람**으로 게임 실행을 유도하고
- 약 3분간 **퍼즐에 집중**하게 해 흡연 생각을 분산시키며
- 퍼즐을 풀 때마다 **니코틴으로 더러워진 폐가 깨끗해지는 모습**을 보여줘 금연 효과를 직관적으로 체감하게 합니다.

## 🎮 게임 방법

네모네모로직 규칙을 따릅니다.

1. 행·열 바깥의 숫자는 그 줄에서 **연속으로 칠해야 하는 칸 수**입니다.
2. 숫자가 여러 개면 **적힌 순서대로** 칠합니다.
3. 덩어리 사이에는 **최소 1칸 이상의 빈칸**이 있어야 합니다.

- 칸을 터치하면 칠해지고, 다시 터치하면 지워집니다.
- 하단 토글 버튼으로 **칠하기 / X 표시** 모드를 전환할 수 있습니다.
- 큰 퍼즐판은 드래그로 스크롤하며, 힌트 영역이 퍼즐 위치에 맞춰 함께 움직입니다.

## 🗺️ 스테이지 구성

| 스테이지 | 내용 |
|---|---|
| Stage 1~3 | 15×15 퍼즐. 폐의 더러워진 부분을 그린 그림으로, 클리어하면 깨끗해집니다. |
| Stage 4 (히든) | Stage 1~3을 모두 클리어하면 해금. 폐 전체 그림이 완성됩니다. |

## ⏰ 핵심 시스템: 알람

- 원하는 시각에 알람을 예약하면, 그 시간에 **Android 푸시 알림**으로 게임 실행을 유도합니다.
- 알람이 울린 뒤 퍼즐을 클리어할 때까지 **경과 시간을 알려주는 알림**이 반복됩니다.
- 퍼즐을 클리어하면 알람이 해제됩니다.
- 알람 설정은 앱을 다시 실행해도 유지됩니다.

## 🛠️ 기술 스택

- **엔진**: Unity 2022.3 (2D)
- **플랫폼**: Android
- **주요 패키지**: Unity Mobile Notifications (`com.unity.mobile.notifications`)
- **이미지 리소스**: Unity 2D 에셋, Gemini 생성 이미지

### 씬 구성

```
StartScene ─┬─ 게임 시작 ─▶ StageScene ─▶ PuzzleScene (Stage 1~4)
            └─ 알람 설정 ─▶ AlarmScene
```

| 씬 | 역할 |
|---|---|
| StartScene | 타이틀. 게임 시작 / 알람 설정 / 종료 |
| AlarmScene | 알람 추가·수정·삭제, ON/OFF |
| StageScene | 스테이지 선택, 해금 상태 표시 |
| PuzzleScene | 퍼즐 플레이, 일시정지·클리어 팝업 |
